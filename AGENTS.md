# Cámara LAN

- Repositorio de publicación: https://github.com/jorgeflores-cloudata/camera_lan
- Por instrucción del usuario, publicar directamente cada actualización completada y comprobada en este repositorio, con una versión nueva. No solicitar confirmación de nuevo para ese paso.
- La primera versión etiquetada es `v1.0.1`. Para cambios posteriores, incrementar la versión de `version.py`, registrar los cambios en `CHANGELOG.md` y crear/subir la etiqueta correspondiente junto con el commit.
- Verificar que la rama y la etiqueta remotas apuntan al commit publicado. No sobrescribir etiquetas existentes ni cambios ajenos.
- Ejecutar las pruebas con `python -m unittest discover -s tests -v`. Las pruebas no deben activar la cámara.
